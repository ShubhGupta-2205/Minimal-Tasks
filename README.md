## 🚀 The Backstory & App Production
Most modern productivity ecosystems force users to juggle multiple fragmented apps—often riddled with subscriptions, paywalls, and intrusive data tracking—just to handle basic tasks, daily habits, and alarms. **Minimal Tasks** was built to solve this exact frustration: a unified, 100% offline, ad-free powerhouse designed with absolute user privacy in mind.

### The Development Journey & Evolution
This project started as an exploration into modern rapid-prototyping workflows using **Google AI Studio** and cloud-based development environments. Through trial and error, this journey unlocked critical engineering insights:
* **Understanding App Ecosystems:** Navigating the distinct differences and architectural constraints of cross-platform frameworks, SDK structures, and PWA limitations.
* **Mastering Prompt Architecture:** Learning how to effectively structure prompts to handle complex native requirements, such as Android permission handling and background service routing.
* **The Value of Precision Engineering:** Discovering firsthand how many modular packages and components are truly required to wire up a production-ready native Android application from scratch.

## ✨ Key Features

* **🔀 Swipeable Multi-Window Architecture:** 
  * **Window 1:** Minimalist Task & Reminder Manager with quick-tick auto-rescheduling.
  * **Window 2:** Advanced Alarms & Habits Hub.
* **🎯 The '+' Multi-Mode Creator:** 
  * Seamlessly toggle between creating **Regular Tasks**, **Normal Alarms**, **Calendar Alarms**, and **Habit Alarms**.
* **⏰ Three Distinct Alarm Modes (Built to Never Fail):**
  * **Normal Alarm:** Fully customizable with a prominent, Alarmy-style massive snooze button right under the digital clock display and toggleable snooze options.
  * **Habit Alarm:** Configurable interval-based reminders (e.g., every X minutes) that intelligently respect user sleep-to-wake hour bounds.
  * **Calendar Alarm:** Direct calendar integration designed to override passive OEM notification limits (turning calendar events and birthdays into actual *ringing alarms*).
* **🎨 Immersive UI & Customization:**
  * Cyber-cyan neon aesthetic (`#00ffff` borders with frosted glass `rgb(0, 0, 0, 0.4)` card styling).
  * Dynamic background theme imports and per-alarm custom background images.
